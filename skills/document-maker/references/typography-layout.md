# Typography & Layout Recipes
**Font pairs** (heading/body): Montserrat/Open Sans | Playfair Display/Lato | Poppins/Inter | Merriweather/Source Sans | Segoe UI Semibold/Segoe UI | Calibri bold/Calibri (safe). Tamil/Indic: Noto Sans Tamil, Latha.
**Scale** (ratio 1.25): 12 / 15 / 19 / 24 / 30 / 38 / 48 pt. Line-height 1.4 body, 1.15 headings. Line length 45-75 chars.
**Grids**: slides 12-col, 0.6in margins, 0.3in gutters; A4 docs 2.5cm margins, baseline 4pt; posters 3-col modular.
**Slide recipes**: Title(left-aligned, accent bar) | Big number(1 stat, 120pt) | 3-card | Split 40/60 image-text | Full-bleed + overlay 60% | Timeline | Matrix 2x2 | Funnel | Process chevrons | Before/after | Quote | Agenda | Chart+insight sidebar | Closing ask.
**Doc recipes**: Report cover(band + title + date) | Callout box(accent left border) | Pull quote | Sidebar facts | Two-column newsletter | Invoice grid | Certificate(border, centred serif, seal area) | One-pager(F-pattern, 3 blocks).
**Poster/banner**: viewing distance rule: headline >= 1in per 10ft; max 3 colours; one focal image; QR + CTA bottom-right.
