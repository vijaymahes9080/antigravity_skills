# Template Library (structures distilled from your reference sites + pro additions)
Note: derived from the categories of SlideTeam, SlideModel, Slidegeeks, TemplateArchive, Miro and Microsoft Create; no template files are copied.

## A. Hackathon / Event (SlideTeam top-10 hackathon proposal, SlideModel hackathon project)
Cover -> Problem & vision -> Objectives/KPIs -> Tracks & themes -> Agenda/roadmap -> Rules & eligibility -> Judging rubric -> Prizes -> Budget -> Sponsorship tiers -> Team & mentors -> Marketing plan -> Risks -> FAQ -> Ask.
**Master add-ons**: sponsor ROI slide, post-event impact report template, participant journey map, judging scorecard (xlsx), registration funnel metrics.

## B. Real-world / Case-study decks (Slidegeeks "real world")
Context -> Challenge -> Approach -> Process diagram -> Results (KPI cards) -> Lessons -> Next steps. Add: before/after, ROI calculator, stakeholder map, SWOT, 30-60-90 plan.

## C. Documents & references (TemplateArchive reference list)
Reference/citation pages (APA 7, MLA 9, IEEE, Harvard), bibliography, glossary, appendix, version/change log, approval sheet. Add: auto-numbered references, DOI links, annotated bibliography.

## D. Documentation boards (Miro documentation templates)
PRD, project brief, kickoff, meeting notes, RFC/decision record, retrospective, user-flow, roadmap, SOP/runbook, onboarding doc. Add: RACI table, decision log, risk register, definition-of-done checklist.

## E. Creative presentation ideas (Microsoft Create)
Storytelling arc, minimal/one-idea slides, full-bleed visual, data-story, before/after, 3-act, pecha-kucha (20x20s), Q&A interactive, infographic one-pager, photo essay.

## F. Pro additions (adaptive)
Pitch deck (12), Business plan, Whitepaper, Case study, Annual/quarterly report, Proposal/RFP response, Resume/CV, Cover letter, Newsletter, Lesson plan, Viva/seminar deck, Project report (MCA: abstract, intro, literature review, methodology, implementation, results, conclusion, references), Lab record, Data-analysis report, Dashboard xlsx, Invoice, Certificate, Poster/Banner, Brochure, Press release, Meeting minutes, Policy/SOP, User manual, Test plan.
