# Pro Design System & QA
**Palettes** (primary/accent/light): Navy 0F2747/F2A900/F5F7FA | Teal 0B3C49/2EC4B6/F0F7F7 | Plum 3B1F4B/FF6B6B/F8F4FA | Forest 1B4332/D4A373/F4F8F5 | Charcoal 22252B/00B894/F4F5F7.
**Type**: Calibri/Segoe UI body; headings bold; scale 44/30/22/16/12.
**Spacing**: 8-pt grid; whitespace >= 25% of slide/page.
**Charts**: one message, title states insight, label directly, max 5 colours.
**QA checklist**: [ ] no overflow/overlap [ ] consistent fonts/colours [ ] every claim sourced [ ] numbers reconcile [ ] spell-check [ ] alt text [ ] notes [ ] file opens clean [ ] no watermark/placeholder text [ ] filename meaningful.
