# Format Matrix & Capability Guide

| Format | File Extension | Engine Module | Editability | Best Use Case |
|---|:---:|---|:---:|---|
| Word Document | `.docx` | `scripts/engine_docx.py` | Full Native | Enterprise reports, academic lab manuals, proposals |
| PowerPoint Deck | `.pptx` | `scripts/engine_pptx.py` | Full Native | Pitch decks, quarterly reviews, training modules |
| Excel Workbook | `.xlsx` | `scripts/engine_xlsx.py` | Full Native | Financial models, tracking sheets, KPI dashboards |
| Publication PDF | `.pdf` | `scripts/engine_pdf.py` | Read-only | Official publications, ready-to-print books, notices |
| Responsive HTML | `.html` | `scripts/engine_html.py` | Web Native | Interactive digital whitepapers, web reports |
| Vector Graphics | `.svg` | `scripts/engine_svg.py` | Vector Native | Architecture diagrams, infographics, visual workflows |
| Rich Text Format | `.rtf` | `scripts/engine_docx.py` / RTF stream | Cross-platform | Legacy system exports, universal text interchange |
| Markdown Text | `.md` | Python core | Plain text | Developer documentation, GitHub READMEs |
