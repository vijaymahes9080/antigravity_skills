## Core Invariant Preserved: Isolated Visual Redesign
When invoked via `/task-ui-redesign-isolated`, the master engine operates under strict **Isolated Presentation Constraints**:
1. **Interface & Contract Freezing**: All component props, event handlers (`onClick`, `onChange`, `onSubmit`), and data schemas remain 100% frozen.
2. **State & Hook Preservation**: Zero alterations to `useState`, `useReducer`, `useEffect`, or API querying hooks.
3. **Aesthetic Elevation Only**: Modernizes typography, spacing rhythm, border aesthetics, surface elevation, and micro-interactions without touching business logic.
4. **Test Selector Stability**: Preserves all `data-testid` attributes and role locators to ensure 100% test suite pass rates.
